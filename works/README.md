# ブラウザゲームの配置

例: `works/my-game/game/index.html` にゲームのHTMLを置き、関連ファイルも書き出し時の構成のまま配置します。

管理画面のWORKSでカテゴリを `GAME`、ステータスを `TEST PLAY` にし、TEST PLAY URLに `works/my-game/game/index.html` と入力します。`/` から始めず相対パスで書けば、公開URL `/top/` で動きます。

作品一覧と詳細に遊ぶボタンが現れ、`#play/作品ID` でゲームを表示します。ゲームはまだ同梱していません。

外部サイトがiframe表示を禁止していたり、ゲームがストレージや特殊なサーバー設定を要求する場合は、そのまま埋め込めないことがあります。「別画面で開く」でも遊べます。iframeはスクリプトとポインターロックを許可し、同一生成元権限・親ページへの移動は許可していません。Unity等のゲームを実際に追加する際は、そのゲームに合わせて動作確認してください。
